# Em’s Elixirs & Roots — E-commerce Website

## How to view it

This project is hosted live here:
          https://emselixirs.com/

## What this is

This is an e-commerce website I built for a holistic apothecary brand concept called *Em’s Elixirs & Roots*. The goal was to create a clean, functional site that could realistically be used to sell products online.

## Why I built it

I wanted to work on something that felt more like a real-world project instead of just a class assignment. This gave me experience building and customizing a full website using tools that people actually use in industry.

## What it does

* Displays products in an online storefront
* Allows users to browse and view product details
* Includes a structured layout for selling items
* Integrates a donation/payment flow using a third-party service
* Designed to be usable across desktop and mobile

## Tech used

* WordPress (Block Editor / Gutenberg)
* WooCommerce
* SiteGround hosting
* HTML & CSS (for customization and styling)

## What I learned

This project taught me a lot about working with existing platforms instead of building everything from scratch. I learned how to:

* Customize WordPress beyond default layouts
* Work with plugins like WooCommerce
* Debug layout and responsiveness issues
* Handle embedding third-party tools (like payment/donation systems)

It also gave me a better understanding of how real websites are actually built and maintained.

## Challenges

One of the biggest challenges was getting everything to behave correctly across devices. The layout and navigation (especially on mobile) took a lot of trial and error to get working the way I wanted.

I also ran into issues with embedding external tools and styling them so they didn’t look out of place, which took some experimenting with CSS.

## If I kept working on it

I’d like to:

* Improve mobile responsiveness even more
* Clean up and simplify navigation
* Add more polished product pages
* Continue refining the overall design

## Notes

This project isn’t just a mockup — it’s built using real tools and hosting, which made it a really valuable learning experience. It’s something I could continue developing into a fully functional small business site.
